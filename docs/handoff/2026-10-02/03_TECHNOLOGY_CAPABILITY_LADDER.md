# Technology & Invention Capability Ladder
**Status:** current design reference  
**Principle:** Build on the best historically plausible Roman/Hellenistic baseline; do not rediscover what already exists.

---

# 1. Core model

For every technology, separate:

1. **Theory** — does someone understand why it works?
2. **Demonstration** — can the principle be shown?
3. **Prototype** — can one working version be built?
4. **Reproducibility** — can another workshop reproduce it?
5. **Production** — can it be manufactured reliably/economically?
6. **Adoption** — are people actually using it?
7. **Institutionalization** — can it survive the original inventor?

The protagonist often starts with Theory. Rome may start with practical craft capability but without generalized theory. Progress happens where these meet.

---

# 2. Mandatory baseline questions

Before any invention scene:

- What did Rome/Hellenistic engineers already have?
- What would an excellent practitioner already know?
- What is tacit craft knowledge versus formal theory?
- What exact bottleneck prevents the next step?
- What resource/manufacturing/institutional capability is missing?
- Is the protagonist improving, combining, standardizing, scaling, redirecting or applying — rather than falsely "inventing"?

---

# 3. Level 0 — Roman Excellence

Starting platform includes sophisticated forms of:

- iron/steel working,
- bronze/brass/copper alloys,
- casting,
- forge welding and heat treatment,
- pumps,
- valves/stopcocks,
- siphons,
- water wheels,
- screws/gears/cams/linkages,
- cranes/hoists,
- concrete,
- glass,
- surveying,
- roads,
- ships,
- mines,
- written administration,
- agriculture,
- medicine,
- large commercial networks,
- Hellenistic automata/pneumatics traditions.

Player fantasy should never require making Romans incompetent.

# 4. Foundational capability layer

## 4.1 Measurement & metrology

Roman local standards and excellent skilled measurement  
→ shared workshop references  
→ calibrated masters  
→ gauges  
→ tolerance bands  
→ inspection  
→ traceability  
→ process control  
→ cross-workshop interchangeability

The key question:

> Can another workshop independently make a part that fits without seeing the original?

This is a central Grand Challenge.

---

## 4.2 Experimental science

Craft trial-and-error  
→ recorded trial conditions  
→ controlled variables  
→ repeated tests  
→ comparison groups  
→ shared protocols  
→ replication by outsiders  
→ institutional experimental culture

The goal is not simply "scientific method invented." It is creating institutions and habits that can generate reliable new knowledge without the protagonist.

---

## 4.3 Mathematical language

Existing geometry/arithmetic  
→ efficient notation  
→ symbolic algebra  
→ systematic trigonometry  
→ logarithmic methods/tables  
→ analytic geometry  
→ calculus concepts when problems demand them  
→ differential equations / probability / statistics later

Introduce math through real problems:
- piston force,
- gear ratios,
- surveying,
- outbreak comparison,
- orbital/astronomical work,
- motion,
- heat,
- electrical systems.

Do not make mathematics a menu lecture.

---

## 4.4 Technical documentation

Craft memory / drawings  
→ consistent symbols  
→ dimensions  
→ numbered parts  
→ revision records  
→ master copies  
→ technical manuals  
→ reproducible diagrams  
→ later mass printing

This is essential to scaling beyond personal teaching.

# 5. Materials Engineering

## 5.1 Ferrous metallurgy

Existing practical iron/steel traditions  
→ material grading  
→ source/batch records  
→ controlled process histories  
→ repeatable carburization/heat treatment  
→ better spring material  
→ better cutting tools  
→ pressure-safe parts  
→ more sophisticated steels where resource/process feasible

Do not "discover" quenching/tempering.

Protagonist advantage:
- property relationships,
- repeatability,
- stress/fatigue/fracture thinking,
- process control,
- application-specific selection.

## 5.2 Copper alloys

Existing bronze/brass craft  
→ controlled composition  
→ reproducible recipes  
→ bearing alloys  
→ valve-seat/body alloys  
→ corrosion/wear selection  
→ brazing/solder specialization  
→ electrical conductor optimization later

## 5.3 Materials testing

File/bend/fracture comparisons  
→ reference samples  
→ wear tests  
→ hardness comparisons  
→ load-to-failure  
→ fatigue observations  
→ thermal/corrosion tests  
→ standardized acceptance tests

# 6. Precision Manufacturing / Machine Tools

Hand tools / lathes / boring traditions  
→ improved rigid lathes  
→ powered boring  
→ drill presses  
→ slide-controlled cutting  
→ milling-like operations  
→ screw-cutting  
→ better measuring fixtures  
→ machine tools that make better machine-tool parts

Critical positive-feedback milestone:

> **Machines begin making better machines.**

This should be a major civilization capability.

---

# 7. Interchangeability / production engineering

Templates  
→ reference gauges  
→ controlled dimensions  
→ batch inspection  
→ independent manufacture  
→ replaceable parts  
→ standardized subassemblies  
→ production planning  
→ maintenance systems

Do not confuse this with "Romans couldn't measure precisely." The leap is **systemic reproducibility across people/shops**.

---

# 8. Mechanical power

Existing animal/water power  
→ better wheel efficiency  
→ gearing  
→ bearings  
→ line shafts  
→ sectional shafts/couplings  
→ distributed workshop power  
→ maintenance/serviceability  
→ load management  
→ speed regulation

Current live design already explored much of this.

---

# 9. Hydraulics

Existing pumps, valves, siphons, pressure systems, floats  
→ improved sealing  
→ better cylinders  
→ pressure-rated fittings  
→ hydraulic press  
→ weighted accumulator  
→ metered valves  
→ pressure indication  
→ calibrated relief mechanisms  
→ hydraulic actuation  
→ multiple actuators  
→ pressure/position regulation  
→ servo-like hydraulic feedback

Important:
- do not invent hydraulics,
- treat modern generalized hydraulic power/control as the acceleration target.

---

# 10. Control systems

Ancient automata / float regulation / practical governors and linkages provide conceptual building blocks.

Protagonist sees generalized abstraction:

> **sensor → comparison → actuator → feedback**

Progress:
- float/level regulation,
- flow regulation,
- mechanical speed sensing,
- governor,
- pressure regulation,
- load regulation,
- sequencing,
- hydraulic amplification,
- machine protection,
- later relays/electrical control.

Romans speak about concrete mechanisms; protagonist recognizes control theory.

---

# 11. Thermal power / steam

Ancient steam/pneumatic demonstrations are not modern industrial engines.

Progress:
known steam effects  
→ experimental boilers  
→ safe pressure systems  
→ useful piston work  
→ better cylinder boring/seals  
→ condensation experiments  
→ rotary output  
→ governor  
→ practical stationary engine  
→ improved efficiency  
→ higher pressure/compound approaches  
→ turbine work later

Do not leap directly to a Victorian industrial ecosystem.

Bottlenecks:
- metallurgy,
- joints/seals,
- machine tools,
- pressure instrumentation,
- fuel economics,
- maintenance,
- regulation,
- training.

---

# 14. Electricity & magnetism

Ancient baseline includes static effects and lodestones, not industrial electrical engineering.

## Stage A — experimental phenomena
- conductors/insulators,
- repeatable electrostatics,
- magnetic experiments,
- charge storage concepts.

## Stage B — electrochemistry
- chemical cells,
- sustained current,
- electrolysis,
- electroplating,
- electromagnets.

## Stage C — generation
Requires convergence of:
- controlled rotary power,
- copper/wire drawing,
- insulation,
- magnetic materials/fields,
- bearings,
- winding,
- instrumentation.

Then:
- crude magneto/generator,
- improved windings,
- field magnets,
- larger dynamos.

## Stage D — applications
- electromagnets,
- telegraphy,
- relays,
- motors,
- lighting,
- instrumentation.

Water power may be the first practical prime mover for generation before steam is mature.

# 24. Economics / accounting / finance

Not simply "teach capitalism."

Potential capabilities:

# 25. Governance / administration / education

Technology survives only if people and institutions can reproduce it.

Capabilities:
- training standards,
- apprenticeship records,
- examination/qualification,
- technical schools,
- libraries,
- scientific societies,
- procurement rules,
- inspection bodies,
- records/statistics,
- stable succession.

Avoid making these modern bureaucracies overnight.

# 28. UI rule

The full capability graph should be mostly hidden under normal play.

The player should normally see:
- currently active work,
- a few available opportunities,
- blockers,
- emerging possibilities.

The system can internally model dozens of latent dependencies without putting a giant tech tree in the player's face.

---

# 29. Pacing rule for technology scenes

Do not let "inspect → prototype → test → refine" become the entire game.

After two meaningful engineering scenes:
- rotate,
- let NPCs continue work,
- surface social/economic/cultural/machine consequences,
- return when something meaningful changed.

Once the bottleneck is understood:
- delegate refinement,
- move to capability/adoption/institution consequences.

---

# 30. North star

The protagonist's advantage is **foresight and synthesis**, not that Romans are stupid.

The civilization becomes interesting when it starts doing things the protagonist did not personally plan.
